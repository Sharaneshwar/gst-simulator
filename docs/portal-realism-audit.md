# GST portal alignment — 1 November 2026

This change uses the official downloaded GST manuals, their embedded screenshots, and the live GSTR-1 tutorial. It aligns the existing simulator's return-entry screens and associated payment/ledger navigation. It is not a declaration that every feature of the GST portal or every downloaded manual is implemented.

## Verified differences addressed

| Area                                              | Previous behaviour                                                              | Current behaviour                                                                                                                                                                                                                              |
| ------------------------------------------------- | ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GSTR-1 invoices and registered/unregistered notes | Single rate dropdown; a second optional list of editable rate selectors         | Fixed table of all supported rates with taxable value, applicable tax heads and cess. Existing single-rate records and JSON imports remain editable.                                                                                           |
| Tax entry                                         | Tax amounts were always recalculated by the backend                             | Auto-calculation with editable amounts that persist through save/reopen. Inapplicable tax heads and supplies without payment are validated.                                                                                                    |
| B2B/CDNR navigation                               | Flat document list                                                              | Recipient-wise counts, recipient drill-down, document search, 10/20/50 records per page, add-again and edit/delete.                                                                                                                            |
| Recipient and POS                                 | POS defaulted to the supplier's state                                           | Recipient GSTIN prefix defaults POS; known local master names populate. POS remains editable and determines the displayed tax heads. State choices display code and name.                                                                      |
| B2B and notes                                     | Missing SEZ/deemed-export and differential controls                             | Mutually exclusive deemed-export/SEZ choices; reverse charge; conditional intra-State IGST; notified differential-percentage control. Calculations and persisted metadata follow these choices.                                                |
| Document numbers                                  | 30-character identifiers; duplicate check limited to one month                  | 16-character invoice/note format; original invoice numbers checked across the financial year, including other invoice tables. Monthly aggregate references remain period-specific.                                                             |
| B2C (Others)                                      | Extra reference input and descriptive rate selector                             | Plain percentage selector with the reference guide available separately, editable applicable tax amounts and a generated internal record reference.                                                                                            |
| B2C (Large)                                       | Missing classification guard                                                    | Inter-State requirement and the ₹1 lakh threshold from August 2024; historical periods use ₹2.5 lakh.                                                                                                                                          |
| HSN summary                                       | One combined list                                                               | Separate B2B/B2C tabs from May 2025, with existing records treated as B2B unless specified otherwise.                                                                                                                                          |
| Filing GSTR-1                                     | Proceed-to-summary opened signing directly                                      | Consolidated summary followed by FILE STATEMENT and the existing signing flow.                                                                                                                                                                 |
| E-way bill integration                            | No return-screen import                                                         | Select generated outward tax-invoice EWB records, import into B2B/B2CL/exports/B2CS, retain source references, report errors and prevent duplicate imports. B2CS imports consolidate by POS/rate. Filed-period and IFF guards remain enforced. |
| GSTR-3B                                           | Generic taxable/tax totals on tiles; table edits in dialogs                     | Tax-head figures on tiles, full-page table editing, calculated net ITC in its proper row, disabled CGST/SGST import-ITC cells, and confirmation before payment.                                                                                |
| Payments                                          | Challan creation/receipt in dialogs; payment mode dropdown                      | Portal-page creation/receipt and payment-mode radio choices. The existing OTP-based practice payment remains.                                                                                                                                  |
| Ledgers                                           | All transactions and a JSON download                                            | From/To filter, opening/closing and running balances for cash/credit, CSV export, print/save-to-PDF. Liability transactions do not claim unsupported historical running balances.                                                              |
| Document item rates                               | Long explanatory option labels inside item selectors                            | Plain percentages, with the separate rate guide retained.                                                                                                                                                                                      |
| Runtime guard screens                             | Registration-required view and challan OTP resend referenced missing components | Both component imports corrected; all frontend component references inspected.                                                                                                                                                                 |

The rate grid uses this app's existing supported rate master, including fractional/historical entries. It does not infer a current legal tax rate from HSN alone. The official tutorial contains screenshots from multiple portal versions; their embedded content is used as evidence rather than assuming every screenshot is the latest screen.

## Completion follow-up — 2 November 2026

The earlier gap list has been implemented for the app’s offered practice workflows: dedicated ECO tables/amendments, queued processing, masters, IRP synchronization, IMS, PMT-09, fixed-sum challans, prior-period reporting, signed adjustments, negative-liability carry-forward, broader registration controls and mixed-rate/ledger Excel imports.

See [workflow-coverage.md](workflow-coverage.md) for the final feature matrix, test results and limits. Default jurisdiction mappings remain explicitly labelled training data; government identity/bank services remain simulated, and historical notifications require instructor calendar settings. This supersedes the earlier validation totals and uncommitted status.
